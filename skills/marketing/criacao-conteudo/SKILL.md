# Criação de Conteúdo

Use esta skill para criar copy completo para o calendário semanal de marketing do negócio.

## Quando usar

- Heartbeat semanal de segunda 08:00 (após relatório do Analista)
- Quando solicitado para criação pontual (promoção, evento, lançamento de prato)

## Tom de voz obrigatório

- **Próximo**: escrever como amigo que recomenda, não como propaganda
- **Apetitoso**: usar palavras sensoriais — crocante, suculento, fresquinho, temperado na hora, feito com carinho
- **Local**: mencionar bairro, cidade ou referência geográfica quando relevante
- **Direto**: sempre terminar com CTA claro

## Etapas

### 1. Ler o briefing da semana

Consultar o relatório do Analista e a prioridade definida pelo Diretor de Marketing. Identificar:
- Dias de menor movimento (para criar promoções)
- Tipo de conteúdo mais eficaz na semana anterior
- Foco da semana (promoção, fidelização, lançamento ou educativo)

### 2. Criar calendário completo

Para cada dia da semana, criar:

**Post de feed**
```
[Primeira linha — máx 150 caracteres, aparece antes do "ver mais"]
[Corpo do texto — complementar, pode ser mais longo]
[Emojis estratégicos — máx 3]
[Hashtags — máx 8: 2 locais, 3 de nicho, 3 de engajamento]
[CTA final]
```

**Story**
```
[Texto principal — máx 80 caracteres]
[CTA ou sticker sugerido: poll, link, contagem regressiva]
```

**Carrossel (3 por semana, nos dias de maior engajamento)**
```
Slide 1: título impactante (máx 50 caracteres)
Slides 2-8: um ponto por slide
Slide final: CTA
```

### 3. Criar promoção para dias fracos

Para cada dia de menor movimento identificado pelo Analista:
```
Nome da promoção: [ex: "Terça do PF especial"]
Oferta: [ex: "Sobremesa grátis no almoço"]
Horário: [horário de funcionamento]
Copy do post: [texto completo]
Copy do story: [versão curta]
```

### 4. Entregar ao Designer

Produzir calendário no formato padronizado com copy e orientação visual para cada peça.

## Proibido

- Usar as palavras "qualidade", "tradição" ou "o melhor" sem mostrar evidência
- Terminar sem CTA
- Post sem menção ao horário de funcionamento em promoções
- Mais de 8 hashtags por post
